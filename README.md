# Гиря49

Мобильное приложение для челленджа **13 ноября — 31 декабря 2026** с одной гирей 16 кг: пошаговая тренировка, повторы или таймер, интервалы отдыха, фото-иллюстрации и схемы техники. Без обязательного аккаунта. Прогресс хранится в браузере на устройстве.

Репозиторий: `Severenit/girya49`. После включения GitHub Pages стандартный адрес приложения: **https://severenit.github.io/girya49/**.

## Открыть на телефоне

1. Откройте HTTPS-адрес приложения в Safari или Chrome и дождитесь полной загрузки.
2. iPhone: «Поделиться» → «На экран “Домой”». Android: меню браузера → «Установить приложение» или «Добавить на главный экран».
3. Выберите день и начните занятие. В режиме повторений отмечайте выполненный подход; таймер подаст сигнал, после которого нужно подтвердить выполнение. На односторонних упражнениях обе стороны показаны отдельно.

После первой загрузки приложение сохраняет офлайн-копию. Звук требует первого касания экрана, вибрация зависит от браузера и телефона. При блокировке экрана сигналы могут задерживаться; во время тренировки держите приложение открытым.

## Перенос прогресса с прежнего адреса

Адрес сайта изменился, поэтому браузер создаст для GitHub Pages отдельное хранилище. Прежние отметки не переносятся автоматически.

1. Откройте **старое приложение в том браузере, где отмечали тренировки**.
2. Настройки → «Скачать копию». Сохраните файл `girya49-ГГГГ-ММ-ДД.json` на устройстве.
3. Откройте новый адрес → Настройки → «Восстановить», выберите сохранённый файл и подтвердите замену прогресса.
4. Проверьте отметки календаря и сохранённую тренировку. Сохраните резервную копию у себя.

Приложение работает без входа в GitHub и не отправляет прогресс на сервер. Файл копии не нужно добавлять в репозиторий. Личные фотографии «до/после», резервные копии и другие персональные файлы также не загружайте в публичный репозиторий. Папка `photos/` содержит только созданные для приложения иллюстрации упражнений.

Очистка данных браузера, приватный режим, другое устройство или другой адрес сайта могут привести к отдельному или пустому прогрессу. Используйте экспорт и импорт для переноса.

## Локальный запуск

Нужен Python 3, зависимости устанавливать не требуется:

```sh
python3 serve.py
```

Откройте http://localhost:8080. Другой порт: `python3 serve.py --port 8090`.

На телефоне в той же Wi-Fi сети можно открыть `http://IP-компьютера:8080`. Компьютер и сервер должны оставаться включёнными. Для установки и офлайн на телефоне нужен HTTPS; локальный HTTP подходит для проверки обычной страницы. Не открывайте `index.html` через `file://`.

## GitHub Pages

В корне репозитория уже находятся все файлы сайта: `index.html`, модули, стили, манифест, иконки и фотографии. Сборки и внешних зависимостей нет.

В **Settings → Pages → Build and deployment** выберите:

- Source: **Deploy from a branch**.
- Branch: **main**.
- Folder: **/ (root)**.

Сохраните настройки и дождитесь публикации. Пустой файл `.nojekyll` позволяет публиковать статические файлы напрямую. Отдельный workflow не нужен. Все адреса ресурсов относительные и поддерживают подпапку `/girya49/`. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Для обновления измените файлы, увеличьте `VERSION` в `sw.js` и отправьте изменения в `main`. Дождитесь новой публикации Pages; закройте вкладки приложения и откройте снова либо используйте кнопку обновления в настройках, когда она появится. На `localhost` и `127.0.0.1` файлы запрашиваются заново, чтобы не мешал старый кэш.

## Программа

Семь циклов **A → кардио → восстановление → B → кардио → C → восстановление**, начиная с пятницы 13 ноября. Всего 21 силовая, 14 кардио и 14 восстановительных дней. Силовые включают разминку и спокойное завершение.

| Неделя | Нагрузка |
| --- | --- |
| 1 | 2 подхода, нижняя граница повторений |
| 2 | 2 подхода, прибавка 1–2 повторений |
| 3 | 3 подхода в первых трёх упражнениях, по 2 в остальных |
| 4 | 3 подхода, верхняя граница повторений |
| 5 | 3 подхода, медленное опускание в приседаниях и тягах |
| 6 | Закрепление качественных повторений |
| 7 | 2 лёгких подхода |

В C упражнения выполняются по кругу. Жим гири лёжа — вариант по выбору; по умолчанию в B стоят отжимания от устойчивой высокой опоры. Махи доступны с третьей недели только после освоения техники и не заменяют становую автоматически. Halo и протяжки не входят в обязательную программу.

Оставляйте запас 2–3 качественных повторения, выбирайте облегчённый вариант и увеличивайте отдых по самочувствию. Фото — иллюстрации положения тела; схема и короткие инструкции доступны в карточке техники. Острая боль, головокружение, боль в груди или необычная одышка — повод прекратить тренировку.

## Проверка и файлы

Для проверок нужен Node.js 18 или новее:

```sh
npm test
```

- `app.js` — интерфейс, таймер и локальное сохранение.
- `program.js` — даты, упражнения, подходы и прогрессия.
- `demos.js` — схемы положений тела.
- `styles.css` — тёмная мобильная тема.
- `sw.js`, `manifest.webmanifest` — офлайн-копия и установка.
- `PHOTO_ASSETS.md` — описание созданных иллюстраций и промпты.
- `tests/` — проверки программы, таймера, сохранения и офлайн-режима.
