# Гиря49

Мобильное приложение для челленджа **13 ноября — 31 декабря 2026** с одной гирей 16 кг: короткие ежедневные занятия, пошаговая тренировка, повторы или таймер, интервалы отдыха, фото-иллюстрации и схемы техники, личные замеры и фото для сравнения. Без обязательного аккаунта. Прогресс хранится в браузере на устройстве.

Репозиторий: `Severenit/girya49`. После включения GitHub Pages стандартный адрес приложения: **https://severenit.github.io/girya49/**.

## Открыть на телефоне

1. Откройте HTTPS-адрес приложения в Safari или Chrome и дождитесь полной загрузки.
2. iPhone: «Поделиться» → «На экран “Домой”». Android: меню браузера → «Установить приложение» или «Добавить на главный экран».
3. Выберите день и начните занятие. В режиме повторений отмечайте выполненный подход; таймер подаст сигнал, после которого нужно подтвердить выполнение. На односторонних упражнениях обе стороны показаны отдельно.

После первой загрузки приложение сохраняет офлайн-копию. Звук требует первого касания экрана, вибрация зависит от браузера и телефона. При блокировке экрана сигналы могут задерживаться; во время тренировки держите приложение открытым.

Во время подхода нажмите **«i» рядом с названием упражнения**, чтобы открыть схему фаз движения, короткие инструкции и вариант легче. Работающий таймер приостанавливается с сохранением времени; после закрытия подсказки нажмите «Продолжить». Все основные упражнения, включая новые D–G, имеют отдельные фото-иллюстрации в тёмном стиле, доступные без сети.

## Замеры и фото

Откройте раздел **«До / после»**, добавьте запись с датой и заполните нужные показатели. Все замеры необязательны. Можно добавить фотографии **спереди, сбоку и сзади**. Для сравнения выберите две даты и одинаковый ракурс: фотографии появятся рядом.

Замеры и личные фотографии хранятся **только в IndexedDB этого браузера**. Они не отправляются в GitHub, в репозиторий или на другой сервер. Статический офлайн-кэш содержит файлы приложения и иллюстрации упражнений; ваши фотографии хранятся отдельно. Другой браузер, адрес сайта или устройство имеют отдельную историю. Очистка данных сайта может удалить её.

В настройках можно скачать **полную JSON-копию**: отметки тренировок, замеры и фотографии. Такой файл содержит личные данные и может быть большим — храните его у себя, не добавляйте в публичный репозиторий. Восстановление новой полной копии после подтверждения **заменяет текущие отметки и историю замеров с фото**. Сначала скачайте копию текущих данных. Старые копии версии 1 по-прежнему восстанавливают тренировки и сохраняют уже имеющиеся замеры и фото.

Кнопка сброса отметок тренировок очищает только тренировки. История замеров и фото остаётся; удаляйте ненужные личные записи отдельно в их разделе.

## Перенос прогресса с прежнего адреса

Адрес сайта изменился, поэтому браузер создаст для GitHub Pages отдельное хранилище. Прежние отметки не переносятся автоматически.

1. Откройте **старое приложение в том браузере, где отмечали тренировки**.
2. Настройки → «Скачать копию». Сохраните файл `girya49-ГГГГ-ММ-ДД.json` на устройстве.
3. Откройте новый адрес → Настройки → «Восстановить», выберите сохранённый файл и подтвердите замену прогресса.
4. Проверьте отметки календаря, сохранённую тренировку и личную историю, если она была в полной копии. Сохраните резервную копию у себя.

Приложение работает без входа в GitHub и не отправляет прогресс на сервер. Файл копии не нужно добавлять в репозиторий. Личные фотографии «до/после», резервные копии и другие персональные файлы также не загружайте в публичный репозиторий. Папка `photos/` содержит только созданные для приложения иллюстрации упражнений.

Очистка данных браузера, приватный режим, другое устройство или другой адрес сайта могут привести к отдельному или пустому прогрессу. Используйте экспорт и импорт для переноса.

## Локальный запуск

Нужен Python 3, зависимости устанавливать не требуется:

```sh
python3 serve.py
```

Откройте http://localhost:8080. Другой порт: `python3 serve.py --port 8090`.

На телефоне в той же Wi-Fi сети можно открыть `http://IP-компьютера:8080`. Компьютер и сервер должны оставаться включёнными. Для установки и офлайн на телефоне нужен HTTPS; локальный HTTP подходит для проверки обычной страницы. Не открывайте `index.html` через `file://`.

## GitHub Pages

В корне репозитория уже находятся все файлы сайта: `index.html`, модули, стили, манифест, иконки и фотографии. Сборки и внешних зависимостей нет.

В **Settings → Pages → Build and deployment** выберите:

- Source: **Deploy from a branch**.
- Branch: **main**.
- Folder: **/ (root)**.

Сохраните настройки и дождитесь публикации. Пустой файл `.nojekyll` позволяет публиковать статические файлы напрямую. Отдельный workflow не нужен. Все адреса ресурсов относительные и поддерживают подпапку `/girya49/`. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Для обновления измените файлы, увеличьте `VERSION` в `sw.js` и отправьте изменения в `main`. Дождитесь новой публикации Pages; закройте вкладки приложения и откройте снова либо используйте кнопку обновления в настройках, когда она появится. На `localhost` и `127.0.0.1` файлы запрашиваются заново, чтобы не мешал старый кэш.

## Ежедневная программа

По умолчанию включены **ежедневные короткие занятия**: ориентир — около 15–20 минут вместе с разминкой, отдыхом и завершением; облегчённые дни могут быть короче. Во всех семи неделях расчётная длительность не превышает 20 минут даже при включённом жиме. Реальное время зависит от ручных подтверждений и дополнительных пауз: отдыхайте дольше, когда это нужно, и не ускоряйте повторения ради цифры.

На каждый из 49 дней есть пять упражнений, разминка и спокойное завершение. Три дня с гирей сохраняются, остальные дни чередуют упражнения с собственным весом и лёгкую работу над контролем движений.

| День недели | Занятие |
| --- | --- |
| Пятница | A · силовая с гирей |
| Суббота | D · упражнения с собственным весом |
| Воскресенье | E · лёгкая практика и подвижность |
| Понедельник | B · силовая с гирей |
| Вторник | F · упражнения с собственным весом |
| Среда | C · силовая с гирей по кругу |
| Четверг | G · лёгкая практика и контроль движений |

Гиря 16 кг нужна только в A, B и C. Лёгкие дни помогают сохранять ежедневный ритм без тяжёлой нагрузки каждый день. При усталости выбирайте облегчение, уменьшайте объём и отдыхайте по самочувствию.

Ежедневный режим можно отключить в настройках и вернуться к исходному ритму: **A → ходьба → восстановление → B → ходьба → C → восстановление**. В нём запланированы 21 силовая, 14 кардио и 14 восстановительных дней.

**Короткий режим:** в A/B/C — два круга во все семь недель, три минуты разминки и минута завершения. Между упражнениями — 30 секунд, между кругами — 60, на смену стороны — 15 секунд; отдых можно продлить. На первой неделе используются нижние цели, на второй — промежуточные, на неделях 3–6 — верхние при сохранении техники. Седьмая неделя возвращает нижние цели. Рост идёт за счёт качественных повторений и контроля, без третьего круга. Облегчённый вариант оставляет один круг.

В D/F короткий режим сохраняет два круга, постепенно меняя рабочие интервалы с 35 до 45 секунд. В E/G — два лёгких круга; при облегчении и в финальную неделю объём уменьшается. Для упражнений, заданных повторениями, таймер короткого режима ограничен **35 секундами**, даже если в настройках выбран больший интервал. Число повторений остаётся ориентиром: закончите подход раньше при потере техники, не пытайтесь вместить все повторы ускорением.

**Расширенный режим** доступен при выключении коротких тренировок в настройках. Он сохраняет первоначальную прогрессию силовых и может занимать 30–50 минут:

| Неделя | Нагрузка |
| --- | --- |
| 1 | 2 подхода, нижняя граница повторений |
| 2 | 2 подхода, прибавка 1–2 повторений |
| 3 | 3 подхода в первых трёх упражнениях, по 2 в остальных |
| 4 | 3 подхода, верхняя граница повторений |
| 5 | 3 подхода, медленное опускание в приседаниях и тягах |
| 6 | Закрепление качественных повторений |
| 7 | 2 лёгких подхода |

В коротком режиме все силовые выполняются по кругу; в расширенном — только C. Жим гири лёжа — вариант по выбору; по умолчанию в B стоят отжимания от устойчивой высокой опоры. Махи доступны только в расширенном режиме с третьей недели после освоения техники и не заменяют становую автоматически. В коротком режиме остаётся становая. Halo и протяжки не входят в обязательную программу.

Настройки коротких и ежедневных занятий независимы. Их изменение применяется к следующей тренировке: уже начатое занятие сохраняет прежние упражнения, интервалы и ограничения таймера.

Оставляйте запас 2–3 качественных повторения, выбирайте облегчённый вариант и увеличивайте отдых по самочувствию. Фото — иллюстрации положения тела; схема и короткие инструкции доступны в карточке техники. Острая боль, головокружение, боль в груди или необычная одышка — повод прекратить тренировку.

## Проверка и файлы

Для проверок нужен Node.js 18 или новее:

```sh
npm test
```

- `app.js` — интерфейс, таймер и локальное сохранение.
- `program.js` — даты, упражнения, подходы и прогрессия.
- `demos.js` — схемы положений тела.
- `styles.css` — тёмная мобильная тема.
- `body-progress.js`, `body-progress.css` — замеры, личные фотографии и сравнение дат.
- `body-store.js` — локальная история в IndexedDB.
- `backup.js` — полная копия и совместимость со старыми копиями тренировок.
- `sw.js`, `manifest.webmanifest` — офлайн-копия и установка.
- `PHOTO_ASSETS.md` — описание созданных иллюстраций и промпты.
- `tests/` — проверки программы, таймера, сохранения и офлайн-режима.
